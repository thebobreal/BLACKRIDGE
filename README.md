# 🎮 Blackridge Prototype

> An ambitious 2D open-world crime prototype inspired by classic sandbox games.

---

## 🧠 Vision

Blackridge Prototype is an evolving 2D top-down open-world project focused on learning advanced game development systems step by step.

The long-term goal is to build a scalable sandbox architecture including:
- Dynamic missions
- AI-driven NPCs
- Police system
- Economy system
- Vehicle mechanics
- Modular world structure

This project is not just a game — it is a technical learning journey.

---

## 🚀 Current Features

- Player movement system
- Basic collision handling
- Camera follow system
- Project structure organized like a studio pipeline

---

## 🛠 Tech Stack

- Engine: Godot 4
- Language: GDScript
- Version Control: Git
- Platform: Windows 11
